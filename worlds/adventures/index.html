Section 03 / The workshop

From manuscript
to playable world.

GreenKappa Worlds brings together the craft of sourcebook design: readable rules, structured lore, player-facing options, maps, encounters, illustrations, and the tools GMs need to run a session without rebuilding it from scratch.

Current materials are development manuscripts, illustrated proof editions and alpha adventures. They have not all been playtested, rights-cleared, or prepared for public distribution. This website catalogs the projects; it does not expose private project archives.
