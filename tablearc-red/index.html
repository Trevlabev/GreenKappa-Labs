01 / Capability map

A campaign OS for the Time of the Red.

Built as its own Electron application—not a D&D theme overlay. The goal is to keep narrative improvisation accountable to character resources, tactical positions, evidence and the Street's long memory.

01 / LIVE PLAY

AI-GM operations

Free-form declared actions, written narration, optional speech synthesis, and reviewable proposed state changes. The AI suggests consequences; the runtime controls what is recorded.

02 / GIGS

Adventure Foundry

Draft and validate structured jobs with scene connections, NPC identities, clues, objectives, faction pressures and possible endings. Activate modules for play.

03 / ENGAGEMENT

Tactical firefights

Initiative, positions, range, cover, ammunition, armor, selected ranged and melee actions, Suppressive Fire, shotgun shells and injury tracking.

04 / NETSPACE

Netrunner operations

Local Access Points and NET Architecture floors, Interface actions, files, passwords and control nodes. Full Black ICE and Demon combat remains a development target.

05 / THE STREET

Living campaign record

Edgerunner dossiers, NPCs, clocks, evidence, relationships, Reputation, eurobucks, downtime, session archives and portable JSON saves.

06 / THE RULES

Medical & spatial tools

Two-meter tactical grids, paths and cover; critical-injury lookup, stabilization, Quick Fixes, Treatments and daily recovery procedures—with explicit GM overrides where needed.

02 / Runtime philosophy

The AI narrates. The game state answers.

The operating principle is open player agency with mechanical accountability. Interesting failure is allowed; invented resources and silent state edits are not.

Declare anything.

Investigate a forged manifest, call in a favor, sneak through a loading dock, put a round through the camera, or jack into an actual NET Architecture.

Adjudicate the cost.

Resolve known RED rules with explicit rolls, position, ammunition and consequences. Unsupported procedures are flagged for GM judgment rather than invented as canon.

Carry it forward.

Review proposed mutations; record HP, gear, leads, clocks, NPC attitudes and losses in persistent campaign state that can survive the session.

03 / Transparency

Development build. Not a commercial release.

The current branch is source-tested and undergoing Windows installation and play-session verification. No public, production-certified installer is being offered on this site.

Build record / v0.5.0

Implemented in source, still under validation

Standalone Electron architecture, native RED interface, OpenAI/Ollama connection paths, a structured Adventure Foundry, tactical/medical modules and save recovery are present in the development source. A prior automated source suite reported 127 passing tests.

What is not finished

  • Complete Cyberpunk RED rules coverage, including all Role Abilities, Black ICE/Demons, cyberware economy and vehicle combat.
  • Long-session AI-provider acceptance and a certified Windows installer.
  • Automatic artwork generation (intentionally excluded from the current roadmap).

No copyrighted rulebook is bundled. AI provider access may require your own API credentials or local model installation.
