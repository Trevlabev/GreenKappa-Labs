          OPERATIONS GUIDE

          Working with Flowglass

          1. Explore: Select a component in the inventory or map. Downstream components glow teal; upstream components glow gold.
          2. Edit: Use the Inspector to change metadata, add relationships, or remove connections. Drag components to rearrange the graph.
          3. Review: Documentation gaps, isolated components and cyclic groups appear under Graph health. Cycles can be intentional review or retry loops.
          4. Share: Export your project as JSON or a selected component's change-impact report as Markdown. Import JSON to continue later.
          5. Move around: Drag empty map space to pan, scroll or use +/− to zoom, and select Fit to reset. Focus a node and press arrow keys for keyboard repositioning.

          All analysis is based solely on a user-provided dependency graph; it does not claim to discover tenant assets, permissions, runtime failures, or actual deployment risk.
